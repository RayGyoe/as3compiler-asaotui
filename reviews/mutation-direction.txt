MUTATION M2 -- applyPayload() does NOT re-resolve when a widget override changes the direction

The fix under test is one line in UiNode.applyPayload:

    if (this.directionOverride != dirBefore) this.resolveStyle(true);

Mutation: comment that line out (nothing else changes).

Command : cd asaotui/ui-demo && ASC_NO_OPEN=1 node run-gallery.cjs
Exit    : 1
Verdict : gallery.done = FAIL colA is at x=24 w=652, expected x=24 w=320;
                            colB is at x=24 w=652, expected x=356 w=320;

Why this is the right redness: `payload()` runs AFTER `resolveStyle()` in a pass, and
the style pointer does not change on a later render, so a direction override set by a
widget would never reach Theme.resolve. The reused `body` slot then keeps laying out in
the PREVIOUS page's direction. Every node still has a rect and every colour is right --
only a hand-computed RECT assertion catches it (page 0's own loginCard is 209.33 wide
instead of 652, because the body was still a row left over from the Widgets page).
